## PR A · the app (new branch `brand-mark`, about an hour)

1. **The mark.** `apps/mobile/src/ui/marks.tsx`: `VersoMark` becomes the real mark, drawn with `react-native-svg` the way `GoogleMark` is (no SVG transformer). Props: `size` (height in points; width follows 882 to 915) and `ground` (`canvas` or `brand`). On the canvas it takes `brand/primary` and the play tint in light mode and `brand/text` in dark; on the brand ground, white and `#CDE8D3`. It keeps `accessibilityLabel="Verso"`. The play tints are constants in the file, since only the mark uses them. Its call sites are the preview route and, unless Rafa says otherwise (default 5 below), the Home header beside the medium word, size 28. The placeholder tile goes. `sparkles` joins the app's icon set so the finder's ask button (wave C) uses it. Specs `shell.md` and `home.md` stop naming the retired v-bars file.
2. **The app icon.** `app-icon-1024.png` becomes `apps/mobile/assets/images/icon.png`, flattened to RGB. The master carries an alpha channel, fully opaque, and App Store Connect rejects an alpha channel on the 1024 icon. `ios.icon` today points at Expo's template Icon Composer bundle, the Expo symbol on a blue gradient; that key is removed so iOS uses the PNG. Android's adaptive icon gets background `#006822`, the white mark centered in the safe zone as foreground and as the monochrome layer. The web favicon is cut from the icon. A small script, `apps/mobile/scripts/brand-assets.mjs`, writes these files so they can be regenerated.
3. **The splash.** It is Expo's default blue `#208AEF` today. It becomes `#006822` with the white mark, at the same 76 pt width.
4. **The holding page** at rankverso.com (`apps/holding`, live) has no icon at all (`href="data:,"`). It gets the mark as favicon, cut from the SVG. This is a separate commit in the same PR, because Vercel rebuilds that page only when its folder changes.
5. **Checks.** Unit tests on the mark's colors per ground and mode, through a pure helper. One simulator build, with screenshots of the home-screen icon, the splash, and the Home header in light and dark. `ios/` and `android/` are regenerated by prebuild and not committed. The icon reaches TestFlight with the next EAS build after merge.
