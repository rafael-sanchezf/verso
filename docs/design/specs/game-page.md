# Game page

Frame `F · Game page` (26:249). Route `app/game/[id]/index.tsx`, pushed at the root so the tab bar is hidden, plus the three form sheets `hours.tsx`, `details.tsx`, `platforms.tsx` in the same folder. Owner: Game page agent. Read [README.md](README.md) first.

**2026-10-07, "Played on" (decision 26).** "I have this game" and its platforms sheet became the played-on step of item 32 when ownership left the product: the same glyph row, line and sheet, now "Played on", marking chips with the `played` variant and writing `setPlayedPlatforms` (`setOwnedPlatforms` is gone); an empty list reads "Not recorded ›", because empty means not recorded rather than not played, and the sheet's clear button reads "Clear".

**2026-10-22, "Rank this" (VER-224, [feature-ideas item 13](../../feature-ideas.md#13-rank-this-not-i-finished-this)).** Built. The primary button reads "Rank this" (Spanish "Clasifícalo"), not "I finished this", and its tap is `startRanking`, never `markFinished`: a game with no entry becomes played with no finished date, a backlog game becomes played the same way, and a Playing, Dropped or Played game keeps its status and gets no write; then the log flow opens, or "Already ranked" offers "Re-rank" as before. The secondary "Rank it" for a played and unranked game is gone, since "Rank this" beside it is the same path; that game has no secondary button. `log=1` now means "open the log flow, or offer Re-rank if the game is already ranked", because a Playing game ranked from Home stays on Home and its long press can reach the page ranked. Finishing is said only on purpose: the Details sheet's Finished date and the Change menu's Played. The status line already showed "Finished {date}" only when a date exists. The lines below are kept as written; where they say "I finished this" or `markFinished` for the primary button, this note wins.

## Layout

- Navigation row: side padding 16, bottom 8: back on the left (`arrow-left` 20 and the `from` param as 17 `text/primary`), `ellipsis` 20 on the right. Use the native stack header with `headerBackTitle` = `from` and a right `ellipsis` button; the frame shows how it should look.
- Content column, side padding 16, gap 18, scrolls.
  - Header row gap 14: `Cover` 100 (radius 10); text column gap 6: title 24 bold (wraps); "2020 · Roguelike, Action" 14 `text/secondary` = year · up to two genre display names; developer 14 `text/secondary`. Missing parts drop out.
  - Score line, row gap 16, each score a value 15 bold `text/primary` beside a source label 12 `text/secondary` with gap 4. Critics: the `metacritic` score labeled "Metacritic", else `igdb_critics` (rounded) labeled "IGDB critics". Players: `steamReviewPhrase(steam.score, steam.scoreCount)` labeled "Steam", else `igdb_users` (rounded) labeled "IGDB users". Decided 2026-09-16 after the first real-data run showed a game with neither Metacritic nor Steam as "93 IGDB 89 IGDB": the IGDB labels always carry their kind, so two fallbacks side by side still read as two sources (rule 21). A source with no data is hidden, never a zero. When `ranking` is set, a third item: `ScoreBadge` small and the label "You" (rule 21; not drawn, the convention).
  - Actions row gap 10, two compact Buttons flex 1: the primary "I finished this"; the secondary by status: no entry or playing → "Add to backlog" (`moveToBacklog`); backlog → "Start playing" (rule 10, `setStatus('playing')`); played and unranked → "Rank it" (opens the log flow without another `markFinished`); dropped → "Add to backlog". When the game is ranked: primary reads "Ranked · {score}" and is disabled, secondary "Move in Ranking" switches to the Ranking tab (provisional).
  - Status line, only with an entry: an 8pt dot (`medium/games` for playing, `text/secondary` otherwise), text 14 `text/secondary`, then "Change" 14 medium `text/primary`. Text: playing → "Playing since {startedAt} · {hours} on {Steam | manual}" dropping missing parts; backlog → "In your backlog since {addedAt}"; played → "Finished {finishedAt}" (or "Played" without a date); dropped → "Dropped". "Change" opens a native action sheet: Backlog, Playing, Played, Dropped, Remove from library (destructive, `removeEntry` after a confirm). Convention, not drawn.
  - Platforms: "Platforms" 18 bold; a chip row with gap 8 that scrolls horizontally: every `game.platforms` entry as a glyph chip (rule 31, Rafa 2026-09-16: a `PlatformIcon` for the platform's family, PlayStation, Xbox, Nintendo, PC, Mac, Linux, iOS, Android, with a short suffix only when two platforms of one family are both present on the game, "4" and "5" for PS4 and PS5, "2" for Switch 2, and the full name as the accessibility label), owned ones as `Chip` owned (border and check), others plain `bg/surface`; tapping a chip toggles ownership through `setOwnedPlatforms`. Then the ownership line, row gap 8: a 16pt checkbox (`medium/games` filled with a `check` when owned, a 1.5px `border/separator` square when not), "I have this game" 14 `text/secondary` with no "on these platforms" wording, spacer, then the owned platforms as glyphs when there are one to three, nothing when more, and "›" 14 medium `text/primary` → `/game/[id]/platforms`, which lists full names (or "Not owned ›" when empty).
  - Details: a title row, space-between: "Details" 18 bold and a 26pt `bg/placeholder` circle with `plus` 18 → `/game/[id]/details`. Stat rows with vertical padding 10, space-between, 15: label `text/secondary`, value medium `text/primary`. Always: Released (full date, else the year, hidden when neither exists); Time to beat ("~22 h ›", tapping shows an alert listing Rushed, Normally, Completely; hidden when `normallySeconds` is null); Added (`addedAt`, entry only). Steam games with a reading: "Playing now" = "{players} on Steam" from `latestPlayerCount`, hidden otherwise (rule 20; work-queue item 13, not in the frame). Personal rows only when filled (rule 20): Started, Finished, Purchased, Hours ("14 h · Steam" or "14 h · entered by hand"), Notes (wraps under its label).
  - About: "About" 18 bold; the summary 14 `text/secondary` clipped to three lines with "more" to expand; hidden without a summary.
- Ellipsis menu (convention): Change status…, Remove from library, Open on IGDB.

## Data

- `gamePage(client, id)` under `['game', id]`; `latestPlayerCount(client, id)` under `['player-count', id]` only when `externalIds` carries `steam`.
- Writes: `markFinished`, `setStatus`, `moveToBacklog`, `setOwnedPlatforms`, `logPlaytime`, `setStartedAt`, `setPurchasedAt`, `setNotes`, `removeEntry`; each followed by `invalidateEntry(queryClient, id)`. `UnknownPlatformError` cannot happen from these chips because they come from the catalog list.

## Behavior

- "I finished this": `markFinished(client, id)`; when `alreadyRanked` is false push `/log/[id]`; when true, an alert "Already ranked" with "Re-rank" (`removeRankingEntry`, `invalidateRanking`, then `/log/[id]`) and "Keep".
- `log=1` param: Home and Search arrive already marked finished, so push `/log/[id]` once the page has loaded, once.
- Sheets, all conventional forms and listed in the PR: `hours` (a numeric hours field, source `manual`, "Clear" removes → `logPlaytime`); `details` (Started, Purchased, Finished with native date pickers, Notes multiline → `setStartedAt`, `setPurchasedAt`, `markFinished` with `finishedAt` for an already played game, `setNotes`); `platforms` (the full platform list as the chips above → `setOwnedPlatforms`, plus "I don't own it" to clear). Each sheet takes `id`, loads `['game', id]`, and dismisses on save.
